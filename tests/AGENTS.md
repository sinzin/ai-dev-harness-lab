# tests/ のルール（Codex 向け）

ルートの `AGENTS.md` に加えて、`tests/` 配下を編集するときのルールです。

- テスト名に `[FR-001]` `[NFR-001]` のように要件IDのタグを付ける。タグが要件とのつながりで、`npm run check:docs` が見る。
- `verify` を通すためにテストを弱めない（削除・skip・期待値の緩和をしない）。落ちたら実装を直す。テスト自体が誤っていると考えるなら、理由を `handoff/to-claude/` に書いて止まる。
- 失敗メッセージには、何が違反で、どこをどう直すかを書く。読むのはエージェントなので、そのまま行動できる文にする。
- ネットワークや現在時刻に依存させない。
