# REQ-001 ToDo リスト

## 背景と目的
AI駆動開発のハーネス（役割分担・検証・レビュー）を試すための題材。ブラウザだけで動く、最小の ToDo リストを作る。

## スコープ外
ログイン、複数端末での同期、期限・優先度・並べ替え、タスクのタイトル編集。

## 機能要件
- **FR-001** タスクのタイトルを入力して追加できる。前後の空白は取り除き、空または空白のみの場合は追加しない。
- **FR-002** タスクを完了／未完了に切り替えられる。
- **FR-003** タスクを削除できる。
- **FR-004** 表示を「すべて／未完了／完了」で絞り込める。
- **FR-005** タスクと完了状態は、ページを再読み込みしても保持される。保存データが壊れていても起動でき、その場合は空のリストから始まる。
- **FR-006** 未完了タスクの件数を表示する。件数は絞り込みの影響を受けない。

## 非機能要件
- **NFR-001** 静的ファイルだけで動く。ビルド工程と、外部ライブラリ・外部URLへの依存を持たない。
- **NFR-002** キーボードだけで追加・切り替え・削除・絞り込みができる。入力欄にはラベルが付き、件数の更新は支援技術に通知される。
- **NFR-003** ロジックは DOM から分離し、Node.js 上で単体テストできる。
