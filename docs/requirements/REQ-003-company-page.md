# REQ-003 会社情報ページ（デモサイト）

## 背景と目的
AI 駆動開発を実際に手で動かして確認するため、デモサイトを作りたい。参照元の会社情報ページ（https://jinzaibase.co.jp/company）のような、簡易的な 1 ページのサイトを作る。

参照元は、ページ上部の見出し領域と、MISSION・VISION・FOUNDER・OUTLINE・COMPANY DECK の 5 つのセクションでできている（2026-11-25 時点）。この**構成**を参考にする。掲載する内容（文章・人名・住所・電話番号・許認可番号など）は、すべて架空のものにする（NFR-008）。

## スコープ外
- 画面の初期表示（1 ページ）以外のコンポーネントの作成。コンポーネントの分割は、のちの作業で行うため、共通コンポーネントなどの考慮は不要。
- 参照元の文章・画像・ロゴ・配色・意匠の転載。実在の企業・個人の情報の掲載。
- 地図などの外部サイトへのリンク、外部フォント、画像ファイル。
- 参照元の「代表メッセージ」の開閉の動作と本文（取得できたのは見出しだけだった）。
- 会社説明資料の実ファイルと、ダウンロードの動作。
- 既存の ToDo サイト（`site/index.html` など）の変更。

## 機能要件
参照元の構成を、1 機能 = 1 つの ID に分けた。
- **FR-011** ページ上部の帯状の見出し領域に、小見出し「COMPANY」とページ名「会社情報」を表示する。
- **FR-012** 見出し領域に、MISSION・VISION・FOUNDER・OUTLINE・COMPANY DECK の 5 つのリンクを表示し、押すと、それぞれのセクションの位置へ移動する。
- **FR-013** MISSION セクションに、ミッションの短いキャッチコピーと、その説明文を表示する。
- **FR-014** VISION セクションに、ビジョンの見出しと、その説明文を表示する。
- **FR-015** FOUNDER セクションに、役職・氏名（日本語と英字）・経歴文を表示する。
- **FR-016** OUTLINE セクションに、会社名・代表・資本金・所在地・海外拠点・電話・従業員数・主要取引銀行・許認可・届出を、項目名と内容の組で一覧表示する。所在地と海外拠点は、複数の拠点を表示できる。
- **FR-017** COMPANY DECK セクションに、見出し「会社説明資料」と、準備中である旨を表示する。
- **FR-018** ページ下部に、このページが AI 駆動開発の検証用のデモであり、掲載内容がすべて架空である旨の注記を表示する。

## 非機能要件
- **NFR-005** 画面幅 360px から 1440px の範囲で、横スクロールなしに、すべての内容を読める。
- **NFR-006** キーボードだけで、ページ内の全リンクを操作でき、フォーカスの位置が見える。ランドマーク（見出し領域・ナビゲーション・本文・フッター）と見出しの階層が、支援技術に伝わる。
- **NFR-007** 文字と背景のコントラスト比は、通常の文字で 4.5:1 以上にする。
- **NFR-008** 掲載する会社名・人名・住所・電話番号・許認可番号などは、すべて架空のものとし、実在の企業・個人・番号を含めない。

REQ-001 の NFR-001（静的ファイルだけで動き、外部ライブラリ・外部 URL に依存しない）は、このページにも適用する。

## 未確定事項
この要件書は、REQ-003 の下書き（あなたが書いた版）と、参照元ページの構成から Claude が起こしたもの。承認の前に、次の点を確認してほしい。
- **参照元の内容をそのまま使うか。** 依頼は「連携した LP の内容でサイトを作成して」だったが、参照元には会社名・実在の人物の経歴・電話番号・許認可番号が含まれる。そのため、**架空の内容に置き換える前提**で起こした（FR-018 と NFR-008 はそのため）。実在の企業の情報を使う場合は、先方の掲載許可が必要。
- 参照元の見た目（青い帯、「+」の意匠）を、どこまで寄せるか。構成だけを参考にし、配色と意匠は独自とする前提。
- 参照元の「代表メッセージ」は、押して開く部分のように見えたが、中身は取得できなかった。スコープ外とした。必要なら、開閉の動作を含む FR を足す。
- FR-018（デモの注記）は、参照元にはない。架空であることを明示するために、Claude が足した。
- 参照元は、LP というより会社情報ページ。その構成を参考にする前提でよいか。
- ID は、REQ-002 の下書き（FR-007〜010、NFR-004）に続けて、FR-011、NFR-005 から振った。REQ-002 を取りやめる場合は、振り直す。
