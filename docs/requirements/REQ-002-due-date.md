# REQ-002 期限日

## 背景と目的
ToDo の各タスクに期限日を付け、期限を過ぎた未完了のタスクに気づけるようにする。REQ-001 の機能は変えず、追加する形で実現する。

## スコープ外
時刻の指定、通知・リマインド、期限日による並べ替え・絞り込み、追加後の期限日の変更・削除、繰り返し。

## 機能要件
- **FR-007** タスクの追加時に、期限日（年月日）を任意で指定できる。指定しない場合、そのタスクは期限日なしで追加される。
- **FR-008** 期限日のあるタスクには、その期限日を表示する。
- **FR-009** 期限日が今日より前で、かつ未完了のタスクを、期限切れとして強調表示する。完了済みのタスクと、期限日が今日以降のタスクは、期限切れとして扱わない。
- **FR-010** 期限日を持たない既存の保存データ（REQ-001 の機能で保存されたもの）を、そのまま読み込める。読み込んだタスクは期限日なしとして、従来どおり動く。

## 非機能要件
- **NFR-004** 期限日の入力と、期限切れの表示は、キーボードだけで操作でき、期限切れは色以外の手がかり（文字）でも伝わる。

## 未確定事項
この要件書は、設計書 DES-002 の依頼内容と README の一行説明から Claude が起こした下書き。承認の前に、次の点を確認してほしい。
- 追加後に期限日を変更・削除できなくてよいか（間違えたら、削除して作り直す）。スコープ外としたが、必要なら要件を足す。
- 「今日」は、使っている端末のローカル日付でよいか。
- 過去の日付を期限日として入力してよいか（許す前提。入力時に警告も拒否もしない）。
- 期限切れのタスクだけを見る絞り込みは不要か（スコープ外とした）。
